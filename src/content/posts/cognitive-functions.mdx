タイプの話を掘っていくと、あるところで急に記号が増えます。

> INFPの主機能は **Fi**、補助機能は **Ne**、第三機能は **Si**、劣等機能は **Te**

いきなり呪文が始まって、置いていかれた人は多いと思います。これは何なのか、そして**自分の診断結果と関係があるのか**を整理します。

先に結論を書きます。**あなたが16Personalitiesで診断したなら、直接の関係はありません。**

## 認知機能とは何か

認知機能（心理機能）は、ユング心理学に由来する考え方です。

情報の扱い方を4種類 — **感覚(S)・直観(N)・思考(T)・感情(F)** — に分け、それぞれに**内向き / 外向き**の2方向を掛けます。

4 × 2 = **8つの機能**ができます。

- Si / Se（内向的感覚 / 外向的感覚）
- Ni / Ne（内向的直観 / 外向的直観）
- Ti / Te（内向的思考 / 外向的思考）
- Fi / Fe（内向的感情 / 外向的感情）

そして各タイプには、**この8つのうち4つが決まった順番で並んでいる**とされます。この並びを機能スタックと呼びます。

## 4文字とは、別のレイヤーの話

ここが混乱の元です。

4文字（E/I・N/S・T/F・J/P）は**指標の組み合わせ**ですが、認知機能は**そこから導出される、別の構造**として扱われます。

そして重要なのは、**機能同士が独立していない**という点です。主機能がFiなら補助機能は外向きの知覚機能になる、といった具合に、相互に依存した組み合わせとして決まります。

これがMBTIの理論的な土台にあたる部分です。

## 16Personalitiesは、これを使っていません

ここが一番伝えたいところです。

**16Personalitiesは認知機能を採用していません。**

理由は理論の土台が違うからです。16Personalitiesは[ビッグファイブ（特性論）をベースに再構成されたもの](/posts/mbti-and-16personalities/)で、ユングの機能理論とは無関係です。

構造の違いが、そのまま出ます。

| | MBTI（ユング由来） | 16Personalities |
| --- | --- | --- |
| 中核 | 8つの認知機能 | 5つの独立した尺度 |
| 軸の関係 | 相互に依存する | **それぞれ独立して測定** |
| 5つ目の軸 | なし | あり（[A / T](/posts/assertive-turbulent/)） |

16Personalitiesは各軸を**独立したスペクトラム**として測ります。つまり「E/Iの結果」と「T/Fの結果」の間に、理論上の連動がありません。

一方、認知機能は連動する前提で組み立てられています。**設計思想が逆**なんですね。

## だから何が起きるか

こういうことが起こります。

**16Personalitiesで「INFP-T」と出た人が、認知機能の解説を読んで「Fiが主機能」と受け取る。**

でもその診断は、Fiを測っていません。4文字が一致しているので繋がっているように見えるだけで、**別の理論の結論を、別のテストの結果に当てはめている**状態です。

これが必ず間違いになるとは言いません。実際に読んで納得する人もいます。ただ、**根拠として繋がってはいない**ということは知っておいた方がいいと思います。

## 認知機能に意味がないわけではない

念のため書いておくと、認知機能そのものを否定したいわけではありません。

「同じINFPでも人によって全然違う」という実感を説明する枠組みとしては、4文字より解像度が高いのは確かです。深掘りしたい人には面白い領域だと思います。

ただし、**それを知るには認知機能を測るテストを受ける必要があります。**無料の16タイプ診断の結果からは出てきません。

## 当サイトの立場

当サイトは、認知機能の話は扱いません。

理由は2つあります。1つは、扱っているのが16Personalities系の4文字だからです。もう1つは、**商品を選ぶという用途には4指標で十分**だからです。

「一人の時間で切り替える人（I）」「使い方が固定されない方が嬉しい人（P）」— この粒度があれば、贈り物も自分用の道具も選べます。Fiの位置を知る必要はありません。

各タイプの指標と、それをどう選び方に翻訳しているかは[タイプ別のページ](/)にあります。
