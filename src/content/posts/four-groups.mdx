16タイプは、4つのグループに色分けされて紹介されることが多いです。

- **分析家** — INTJ / INTP / ENTJ / ENTP
- **外交官** — INFJ / INFP / ENFJ / ENFP
- **番人** — ISTJ / ISFJ / ESTJ / ESFJ
- **探検家** — ISTP / ISFP / ESTP / ESFP

なんとなく眺めていると気づきにくいのですが、**この分け方、左右で基準が違います。**

## 使っている軸が違う

並べてみると分かります。

見えましたか。

**N（直観）の8人は T/F で割られ、S（感覚）の8人は J/P で割られています。**

同じ「4グループ」なのに、左半分と右半分で使っている2本目の軸が違う。これはかなり不思議な作りです。

## なぜこうなっているのか

これは16タイプ独自の発想ではなく、**ケルシー（David Keirsey）の気質論**という別の枠組みに由来する分け方です。

その考え方の背景を、ざっくり言うとこうなります。

**Nの人は「何を大事にするか」で分かれる**

抽象的なものを扱う人たちなので、**何のために抽象を使うか**が行動を大きく変えます。仕組みや理屈のためならNT、人や理想のためならNF。ここでT/Fが効いてくる。

**Sの人は「どう関わるか」で分かれる**

具体的な現実を扱う人たちなので、扱う対象は似ています。違いが出るのは**現実への向き合い方**です。秩序立てて維持するならSJ、その場で反応して動くならSP。ここでJ/Pが効いてくる。

つまり「N と S では、行動の差を生む軸がそもそも違う」という主張が、この非対称に埋め込まれています。

## この分類が便利なとき

16タイプは多すぎて扱いにくいので、**4つに落とすと実用的**な場面はあります。

- 相手のタイプが分からないが、雰囲気で大枠を掴みたいとき
- 贈り物の方向性だけ先に決めたいとき

たとえば「番人っぽい人」と分かれば、**用途がはっきりしていて、質が良くて、長く使えるもの**という方向が定まります。「探検家っぽい人」なら、**その場で楽しめて、使い方が自由なもの**。

これだけでも、選択肢はかなり絞れます。

## この分類が雑になるとき

一方、注意も必要です。

**同じグループ内の差が消えます。**

INTJとENTPは両方「分析家」ですが、実際の印象はかなり違います。片方は計画を先に固めたがり、もう片方は思いつきで議論を広げたがる。**E/I と J/P という、生活実感に直結する2軸がまるごと無視されている**からです。

グループはあくまで**入口**で、実際に人と接するときや物を選ぶときは、4指標に戻った方が精度が出ます。

## 当サイトでの使い方

各タイプのページには、そのタイプの4指標と、それをどう選び方に翻訳しているかを表で出しています。

グループで大枠を掴んで、指標で具体化する。この順番が使いやすいと思います。
